## 1. 第一次検証との関係

**第一次(v1.0–v1.3)の結果は確定しており、本版はそれを上書きしない。** 論文は両者を併記する。

### 1.1 なぜ第二次を行うのか(動機の記録)

動機を後から美化しないために記録する。**第一次は最低要件を満たした時点でプールを閉じており、その時点で未判定の CT 候補が4件、胸部X線候補が2件残っていた**(`docs/h2_candidate_scan_v1.md` の CAND-02、-03、-05、-06、-09、-10)。プール要件は「採用 ≥3 研究、≥15 条件点」であり、これを満たしたため運用上は正しい。しかし候補表は公開リリースに含まれており、**自ら「優先度:高」と記した候補が判定されずに残っている**。

第二次の第一の目的は、その未判定を解消することである。第二の目的は、非CT枠を**モデルが記述できる regime で**埋めることである(§2)。

## 2. C1 の改訂 — modality 軸から雑音 regime 軸へ

### 2.1 改訂の理由

v1.0 の C1 は「CT または胸部X線」という **modality 列挙**であった。第一次で非CT枠が埋まらなかったのは偶然ではない。胸部X線は解剖学的背景が検出を律速する典型的な条件であり、**本モデルは解剖学的雑音の項を持たない**(論文 §5.1、§6)。同じ理由でマンモグラフィ・トモシンセシスへ列挙を広げても、モデルが記述できないと自ら述べている領域へ踏み込むだけである。

モデルの適用範囲は modality ではなく**雑音 regime** で決まる。論文 §5.1 は既にそう述べている:

> The results are stated for tasks in which quantum and neural noise are the limiting terms.

C1 はその適用範囲を反映するよう改訂する。**これは緩和ではなく、適用範囲の正確化である。**

### 2.2 改訂後の C1(凍結)

| # | 基準 | 検査 |
|---|---|---|
| C1a | **線形撮影系**であり、系の解像特性と雑音特性が MTF(または TTF)と NPS で特徴づけられ、それらが当該研究または当該装置の公表特性文献から得られる | `modality` が許可集合に含まれ、`mtf_source` と `nps_source` が非空 |
| C1b | 検出タスクである | `task_type == "detection"` |

**許可 `modality` 集合(凍結):** `ct`、`chest_radiography`、`projection_radiography`、`fluoroscopy`、`digital_mammography`、`dbt`。

**C1 は背景の種類で除外しない。** 背景は §4 の記述変数 `background_class` として全件記録するが、除外力を持たせない。理由は §4.1 に記す。

### 2.3 C2–C6 は v1.0/v1.2 のまま(再掲、変更なし)

| # | 基準 |
|---|---|
| C2 | モデルの宣言済み入力に対応する **≥2 条件軸**で人間観察者性能が数値報告(v1.2 の語彙確定に従う) |
| C3 | **≥4 条件点** |
| C4 | 表示・読影条件の記載を記録。**除外力を持たない。** 補った値は `assumed_parameters` として全件明示 |
| C5 | 性能指標が AUC・2AFC の PC・$d'$ のいずれか。3択以上の m-AFC の PC は除外 |
| C6 | 図からの digitize は独立2回で最大偏差 **±5%** 以内 |

|---|---|

**未達の場合の帰結を先に固定する。**

## 4. 記述変数 `background_class`(除外力なし)

全採用研究に、当該研究が検出タスクの背景をどう記述しているかを記録する。**研究自身の記述に基づき、起草者が推定しない。**

| 値 | 意味 |
|---|---|
| `uniform_or_phantom` | 均一背景、または構造を持たない/既知構造のファントム。量子雑音が律速と当該研究が記述、あるいは背景に解剖構造が無い |
| `anatomic` | 患者由来の解剖構造を背景に持つ |
| `not_stated` | 当該研究の記述からいずれとも判定できない |

正本は `ptx/external.py` の `BACKGROUND_CLASS` と `StudyRecord.background_class`(**既定値を持たないフィールドとして宣言**し、記録の欠落がレコード構築時に例外になるようにする。v1.3 の `task_congruence` と同じ扱い)。

### 4.1 なぜ除外基準にしないのか

**起草者は第一次の per-study 結果を知っており、paul2007 が唯一の閾値未達であることを知っている。** paul2007 は肺結節検出であり、`anatomic` に分類される公算が高い。この状況で `background_class == anatomic` を除外基準にすれば、**結果を見てから不都合な研究を落とす基準を書いたことになる。** それは本事前登録が存在する理由そのものに反する。

したがって `background_class` は**記述変数に留め**、除外力を持たせない。v1.3 が `task_congruence` に対して行ったのと同じ扱いである。

### 4.2 事前に書く予測と、外れた場合の帰結

**予測(本コミット時点で記録):** `uniform_or_phantom` 層の研究内 $\rho$ の中央値は、`anatomic` 層のそれ以上である。

この予測は、論文 §5.1 が述べる適用範囲(量子雑音と神経雑音が律速のタスクに限る)から導かれる。

**外れた場合の帰結を先に固定する。** `anatomic` 層が `uniform_or_phantom` 層と同等以上の一致を示した場合、**論文 §5.1 の適用範囲記述が過度に狭いことになる。** その場合は §5.1 と §6 の解剖学的雑音に関する記述を弱める方向で改訂し、そう改訂した理由として本節を引く。**どちらに転んでも報告する。**

**層別は成功条件に一切入らない。** v1.3 §A.2 と同じく、ある層だけを取り出して H2 を救うことは禁じる。

## 5. 解析と判定(第一次と同一)

第一次から変更しない。

| 判定 | 条件 |
|---|---|
| 研究単位の成功 | 研究内 Spearman $\rho \ge 0.7$ |
| プール単位の成功 | 採用研究の過半で研究単位成功、かつプール校正の Spearman $\rho \ge 0.7$ |
| **H2(第二次)棄却** | 採用研究の過半で $\rho < 0.7$、またはプール校正が単調でない |

- 不一致研究は除外せず報告する。
- p 値は計算しない(v1.0 §5-5)。
- 実行は**プールを閉じた後に一度だけ**。`ptx/h2_analysis.py` の `gate_pool` と同じ門を第二次プールにも適用する。

## 7. 実装の前提変更 — acquisition 段の MTF/NPS 直接入力

C1 の改訂により、CT 以外の系を扱う必要が生じる。現行の `ptx.condition.Acquisition` は CT 専用の入力(再構成カーネル名、HU 基準の雑音、スライス厚、ramp 指数)を取るため、非CT系を表現できない。

**本版の凍結後、性能データの抽出前に**、`Acquisition` に測定 MTF/NPS を直接与える経路を追加する。

- 追加は**入力経路のみ**であり、検出可能度の定式化(`ptx/detectability.py`)は変更しない。
- 既存の CT 経路の出力が**ビット単位で不変**であることをテストで固定する。第一次の結果が再現できなくなる変更を禁じるためである。
- この追加は、計画書 §2.1 と論文が主張する「formulation は modality-agnostic」を実装で裏付けるものでもある。現状はその主張をコードが支えていない。
