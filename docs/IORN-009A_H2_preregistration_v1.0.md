# H2 外部検証 事前登録(v1.0)

**プロジェクト:** IORN-009A(Institute of One Research Note 009A)
**上位文書:** `docs/IORN-009A_research_protocol_v0.4.md` §8(Phase 2)
**凍結日:** 2026-08-23
**凍結の証拠:** 本文書を追加したコミットのタイムスタンプ。**文献の系統調査はこのコミットより後に開始する。** 論文 Methods からこのコミットを参照する。

## 0. 本文書の目的

計画書 §8 の包含基準を、**機械的に検査できる形**に落として凍結する。選定を基準先行にすること(=データを見てから基準を動かさないこと)が H2 の外部検証としての価値を決めるため、基準・スキーマ・解析・棄却条件をすべて先に固定し、実装(`ptx/external.py`)で検査可能にしてある。

以後の変更は本文書の版を上げ、**変更理由と変更時点で既に閲覧していた研究**を明記して行う(事後的な基準変更を隠さない)。

## 1. 対象仮説と成功・棄却条件

**H2:** 本統合モデルの予測は、既報の人間observer実験(条件別AUC・PC・$d'$)の**条件間順位**を再現する。

| 判定 | 条件 |
|---|---|
| 研究単位の成功 | 研究内 Spearman $\rho \ge 0.7$ |
| プール単位の成功 | 採用研究の過半で研究単位成功、かつプール校正(研究内順位を標準化して結合)の Spearman $\rho \ge 0.7$ |
| **H2 棄却** | 採用研究の過半で $\rho < 0.7$、またはプール校正が単調でない(負の相関) |

不成功も**必ず報告する**。不一致研究は除外せず、不一致の原因(表示条件の未記載・タスクの非適合等)を記述する。

## 2. 包含基準(凍結)

計画書 §8 の (i)–(iv) を以下に操作化する。

| # | 基準 | 検査 |
|---|---|---|
| C1 | 適用範囲内モダリティ(CT または胸部X線)の検出タスク | `modality` が許可集合に含まれる |
| C2 | 線量・病変サイズ・コントラスト・再構成/処理のうち **≥2 条件軸**で人間観察者性能が数値報告 | `len(condition_axes) >= 2` |
| C3 | 順位相関が意味を持つ **≥4 条件点** | `len(conditions) >= 4` |
| C4 | 表示・読影条件が再現可能な程度に記載 | `reports_display_conditions` と `reports_reading_conditions` の記録。**いずれかが偽でも除外しない**が、補った値は `assumed_parameters` として全件明示する(§4) |
| C5 | 性能指標が AUC・2AFC の PC・$d'$ のいずれか | `metric` が許可集合に含まれる。**3択以上の m-AFC の PC は除外**($d'$ 変換に追加仮定を要するため) |
| C6 | 図からの digitize は **±5%** 精度で可能 | 独立2回 digitize の最大偏差 `digitisation_repeat_max_deviation <= 0.05`(本文表から取得した場合は 0) |

**プール要件(凍結):** 採用 **≥3 研究**、合計 **≥15 条件点**、うち **≥1 研究は非CT(胸部X線)**。最後の要件は計画書 §2.1 の「formulation は一般、validation は CT+胸部X線」という主張範囲を実体として支えるものであり、**充たされない場合は汎用性の主張を取り下げる**(CT限定の主張に落とす)。実装では必須フラグ `generality_check` として検査する。

## 3. 除外の記録

**スクリーニングした全研究を記録する。** 除外した研究は、識別情報・落ちた基準(C1–C6)・除外理由の自由記述を `data/h2_studies.json` の `screened` に残す。除外件数と理由の内訳を論文の補遺に表として出す(選択的検証の疑いを排除するため)。

## 4. 補った条件の扱い(重要)

既報論文は表示条件(輝度・視距離・拡大率・ウィンドウ幅)を書いていないことが多い。補完は次の規約で行う。

1. 報告値があればそれを使う。
2. 無い場合は**この事前登録で宣言した既定値**を使う: 視距離 500 mm、輝度 100 cd/m²、拡大率(解剖学的)1.0、ウィンドウ幅 1500 HU、表示画素ピッチ 0.2 mm、8bit。
3. 補った項目は条件ごとに `assumed_parameters` に列挙し、論文の補遺表に出す。
4. **感度分析:** 補完が結論を左右しないことを、既定値を §5.4 の区間(視距離 400–700 mm、輝度 50–200 cd/m²、拡大率 1.0–2.0)で振って研究内 $\rho$ が符号を変えないことで示す。符号が変わる研究は「表示条件未記載により判定不能」として本文に明示する。

$\eta_{\mathrm{cog}}$ と $\kappa$ は順位に影響しない範囲で自由度を持つ($\eta_{\mathrm{cog}}$ は $d'$ を定数倍するのみ)ため、順位相関の判定には効かない。プール校正では研究内標準化により吸収される。

## 5. 解析(凍結)

1. **主要:** 研究内 Spearman $\rho$(条件点間)。研究ごとに $\rho$・$n$・成功判定を報告。
2. **副次:** プール校正 — 研究内で予測・実測をともに順位標準化してから結合し、Spearman と散布図を出す。
3. **異質性:** 研究間の $\rho$ の分布(最小・中央値・最大)を記述。メタ解析的な統合推定は行わない(研究数が少なく、異質性が大きいため)。
4. **指標変換:** 校正プロットのためだけに AUC・PC を $d'$ に変換する($d' = \sqrt{2}\,\Phi^{-1}(\mathrm{AUC})$、2AFC は $d' = \sqrt{2}\,\Phi^{-1}(\mathrm{PC})$、等分散2正規モデル)。**順位判定は変換前後で不変**なので、主要解析は変換に依存しない。
5. **多重比較:** 研究ごとの $\rho$ に対する有意性検定は行わない(事前設定した閾値 0.7 との比較のみ)。$p$ 値の羅列で「有意」を作らない。

## 6. データスキーマ

正本は `ptx/external.py` の dataclass 定義(`SCHEMA_VERSION = "1.0"`)。登録簿は `data/h2_studies.json`。

**研究レコードの必須項目:** 研究ID / 引用 / モダリティ / タスク / 条件軸 / 性能指標 / 取得方法(本文表 or digitize) / 表示条件の記載有無 / 読影条件の記載有無 / 汎用性検証枠フラグ / 読影者数 / digitize 再現偏差 / 条件点(ラベル・実測値・報告された物理パラメータ・補った物理パラメータ)。

**除外レコードの必須項目:** 研究ID / 引用 / 落ちた基準 / 除外理由。

## 7. 予期される限界(先に書く)

- 既報研究は表示条件の記載が薄く、C4 を厳格に適用すると採用ゼロになりうる。よって C4 は除外基準ではなく**補完と感度分析の対象**とした。この選択自体が事後的でないことを本文書の凍結時点が保証する。
- 研究間の観察者集団・タスク定義・判定基準の差は統合できない。だから主要指標を**研究内順位**に限定している。
- 順位一致は絶対水準の妥当性を意味しない(リスク登録簿 #11)。
