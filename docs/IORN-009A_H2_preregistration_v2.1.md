# H2 外部検証 事前登録 v2.1(プール構成の曖昧さの解消)

**上位文書:** v1.0(`6b77ee3`)/v1.1(`3ca25e2`)/v1.2(`a0029f9`)/v1.3(`dddcb01`)/**v2.0(`0afd87d`)**。**いずれも改変しない。**
**凍結日:** 2026-08-29
**凍結の証拠:** 本文書を追加したコミットのタイムスタンプ。

---

## A. 何を直すのか

v2.0 §3 は第二次プールの要件を「採用研究数 ≥6、合計条件点 ≥60、非CT研究 ≥2」と定めた。**しかし第一次で採用済みの3研究(yu2013、paul2007、leng2013)が第二次プールに含まれるのかを規定していない。** §1 の「独立したプールを新たに構成し」は、次の二通りに読める。

- **読み A(継承):** 第二次プール = 第一次の3研究 + 新規採用。C1–C6 は不変なので、第一次の3研究は第二次の基準を構成上満たす。
- **読み B(排他):** 第二次プールは新規採用のみ。

要件が ≥6 であるため、**この違いは「新たに3研究を採ればよい」か「新たに6研究を採らねばならない」かの違いになる。** 起草時に気づかなかった欠陥である。

---

## C. 解消 — 継承を認め、同時に新規採用の下限を課す

**読み A(継承)を採る。ただし v2.0 §3 の要件に新規採用の下限を追加する。**

| 要件 | 値 |
|---|---|
| 採用研究数(継承分を含む) | **≥6**(v2.0 から変更なし) |
| **うち第二次で新規に採用された研究** | **≥3**(本版で追加) |
| 合計条件点 | **≥60**(v2.0 から変更なし) |
| 非CT研究 | **≥2**(v2.0 から変更なし) |

### C.1 継承を認める理由

C1–C6 は v1.0 から一字も変えていない。したがって第一次の3研究は第二次の基準を**構成上**満たしており、これを除外することは有効な証拠を捨てることになる。第二次の目的は「検証を厚くすること」であって「別の検証をもう一つ作ること」ではない。論文が報告するのは、薄い検証二つではなく、第一次の結果と、それを含んで厚くした第二次の結果である。

### C.2 新規採用 ≥3 を課す理由

**継承を認めるだけでは、第二次が第一次の研究だけで要件を満たしうる。** それは検証を厚くしたことにならない。新規採用の下限を課すことで、第二次は**必ず新しい証拠を含む**。

この下限は、検索結果を見た後に決めている以上、**緩い側に倒れていないことが確認できる形でなければならない。** 現時点で新規候補は実質5件であり、そのうち3件が C1–C6 を通る保証はどこにもない。**この下限は現実に達成できないかもしれず、その場合は第二次が成立しなかったと報告することになる**(v2.0 §3)。緩和ではない。

### C.3 独立でないことの明示

継承を認める以上、**第一次と第二次のプールは3研究を共有し、統計的に独立ではない。** 両者のプール校正 $\rho$ を独立な二つの検証として扱ってはならない。論文は両方を報告する際に、**共有している研究を明示し、第二次が第一次を含むことを述べる。** 二つの一致を独立な再現として提示することを禁じる。

## D. 検索語について(変更しない)

§6.2 の6語のうち3語が 0 件であった。PubMed は語をすべて AND で結合するため、7〜11語の検索式は極めて限定的になる。**これは凍結時に予見すべきであった設計上の弱点である。**

**しかし検索語は変更しない。** 結果を見てから検索語を足すことは、検索の事後拡張そのものである。0件であったこと、その理由が AND 結合による過剰な限定であることを**そのまま記録し、論文の Limitations に書く。**

第三次を行う場合は、**本版の結果を見る前に**検索式を設計し直した v3.0 を凍結する。本版でそれを行わない。
