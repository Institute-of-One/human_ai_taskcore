# H2 外部検証 事前登録 v1.1(改訂・追記)

**上位文書:** `docs/IORN-009A_H2_preregistration_v1.0.md`(凍結 2026-08-23、コミット `6b77ee3`)。**v1.0 は改変しない。** 本文書は v1.0 §0 の改訂手続きに従う追記であり、v1.0 と併せて読む。
**改訂日:** 2026-08-23
**改訂の凍結:** 本文書を追加したコミットのタイムスタンプ。

## A. 改訂内容(1点のみ)

**C2 の「条件軸」に画素サイズ・表示マトリクスを含める。**

v1.0 の C2 は計画書 §8 の列挙(線量・病変サイズ・コントラスト・再構成/処理)を条件軸としていた。v1.1 では条件軸の語彙を次に確定する。

| 語彙 | v1.0 | v1.1 |
|---|---|---|
| `dose`, `lesion_size`, `contrast`, `reconstruction`, `processing` | ○ | ○ |
| `pixel_size`, `displayed_matrix` | (不明確) | **○(本改訂で追加)** |

条件軸は上記の語彙に限る(自由記述を認めない)。実装は `ptx/external.py` の `ALLOWED_AXES` が正本であり、語彙外の軸名は C2 で落ちる。

**他の基準(C1・C3・C4・C5・C6)、プール要件、解析、棄却条件は一切変更しない。**

## B. 本改訂が結果駆動でないことの宣言

改訂時点で実施済みの作業は、**候補文献のタイトル・抄録レベルの閲覧のみ**である。すなわち:

- **条件別の性能データ(AUC・PC・$d'$)の抽出は一切行っていない。**
- **図からの digitize は一件も行っていない。**
- **モデル予測との比較(順位相関の計算)は一件も行っていない。**
- したがって、本改訂によって採否が変わる研究の**検証結果は改訂時点で未知**である。

改訂時点で閲覧していた候補の一覧は `docs/h2_candidate_scan_v1.md`(CAND-01〜CAND-12、Cowork セッション、v1.0 凍結コミット後に作成)に記録されている。個別の研究名を改訂の根拠としては用いない(§C を参照)。

## C. 改訂の内在的根拠

**H3 が表示画素ピッチを中心機構に置くため、画素サイズ・表示マトリクスを C2 の条件軸として認めることはモデルの検証範囲と整合する。**

本モデルにおいて画素ピッチと拡大率は、内部雑音床が $|H_{\mathrm{display}}|^2$ の外に置かれることを通じて検出能に効く唯一の経路であり(計画書 §5.1)、H3 はその経路そのものを仮説にしている。画素サイズを条件軸として振った既報研究は、モデルの中心機構を直接検証する条件軸を提供する。これを「条件軸ではない」として排除する読みは、検証対象と検証データの間に不整合を生む。

## D. 解析への追記(v1.0 §5 に1行追加)

**感度分析:** 主解析は v1.1 の基準で構成したプールで行う。**併記として、v1.0 の基準(語彙を `dose`/`lesion_size`/`contrast`/`reconstruction`/`processing` に限る厳格読み)のみで構成したプールについても、研究内 $\rho$ と H2 判定を報告する。** 両プールで結論(研究単位の成功判定とプール判定)が変わらないことを示せば、本改訂は結論に対して無害である。変わる場合は**両方を並べて報告し、改訂が結論を作ったことを明示する**(隠さない)。

プールの切り分けは実装で機械的に行う(`ptx/external.py` の `pool_partition`)ため、事後の裁量が入らない。
